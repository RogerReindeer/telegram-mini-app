# Qinghe RPG + Читалка: план обновления v1

Дата спецификации: 2026-08-29.

Этот пакет описывает изменения двух Telegram Mini Apps для общей покупки двух независимых валют:

- Qinghe RPG использует валюту **Платина**;
- читалка использует валюту **Монетки**;
- одна подтверждённая покупка валютного пакета начисляет обе валюты;
- после начисления балансы расходуются независимо.

Пример:

```text
Покупка пакета 500
  -> +500 Платины в Qinghe RPG
  -> +500 Монеток в читалке

После покупки:
  трата 100 Платины не изменяет Монетки;
  трата 50 Монеток не изменяет Платину.
```

## Ключевое решение

Баланс не синхронизируется постоянно. Покупка порождает два независимых ledger-события с общим `purchase_id`. Это исключает ситуацию, когда игровая трата случайно уменьшает доступный баланс в читалке.

## Границы пакета

Это техническая спецификация и черновики миграций. SQL нельзя применять к production без резервной копии, проверки реальной схемы и запуска на staging.
